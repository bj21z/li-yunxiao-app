# 云上小百花 · 李云霄艺术档案 V1.1.0

## 本次升级
- 修复“云霄小考”只能停留在第一题的问题：现支持5题连续作答、即时反馈、下一题、成绩页、重答和随时退出。
- 修复弹窗关闭体验：加大关闭按钮，支持点击遮罩、键盘 Esc、焦点回退及 iPhone 安全区。
- 重构“云霄动态”：不再从前端访问 Google News / Jina 等在中国大陆不稳定的境外服务。
- 动态改为同源 `data/dynamics.json` 资料包，点击“同步”会读取网站最新发布版本；无网时自动读取本机缓存。
- 全部核心 CSS、JS、图片和数据均为本地资源，不依赖境外 CDN、字体或脚本。
- 新增数据版本和更新时间提示、Toast反馈、异常兜底、深色主题记忆。

## 部署
将本文件夹内全部内容上传到 Cloudflare Pages、GitHub Pages 或任意静态网站空间。

注意：不要只上传 index.html，必须保留以下目录结构：
- assets/
- data/dynamics.json
- app.js
- styles.css
- sw.js
- manifest.webmanifest

## 动态更新方法
编辑 `data/dynamics.json` 后重新部署即可。用户点击“同步”时会拉取最新版，不会跨域，也不会依赖境外搜索服务。

## 中国大陆可用性设计
核心页面离线可运行；联网仅用于读取本站同源 JSON 和打开公开来源链接。实际访问速度仍取决于您选择的托管平台和用户网络环境。若以中国大陆稳定访问为最高优先级，建议使用已备案的中国大陆对象存储/静态网站托管及自有域名。
