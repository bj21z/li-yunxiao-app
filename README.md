# 云上小百花 · 李云霄艺术档案

## 运行
直接打开 `index.html`，或把整个文件夹上传到 GitHub Pages / Cloudflare Pages。建议使用 HTTPS，以启用 PWA 安装与离线缓存。

## 结构
- `index.html`：主页面
- `styles.css`：Apple 风格响应式设计
- `app.js`：动态、收藏、签到、云笺、问答、主题切换
- `manifest.webmanifest` + `sw.js`：PWA 与离线缓存
- `assets/`：图标与剧照

## 实时动态
点击“更新”后，程序会尝试通过公开 RSS 聚合源读取近 30 天动态；若网络、跨域或中国大陆访问条件导致失败，会自动回退到内置、已核验内容。生产环境建议部署自己的 Serverless API，并只抓取获授权或允许转载的来源。
